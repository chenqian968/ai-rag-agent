# AI Agent 入门指南

## 什么是 AI Agent

AI Agent(智能体)是一种能够感知环境、自主决策并执行动作的 AI 系统。与传统的聊天机器人不同,Agent 不仅会"说话",还能"做事"——它可以调用工具、查询数据库、执行代码、访问网页等。

一个典型的 Agent 通常包含四个核心组件:大语言模型(LLM)作为"大脑"、工具(Tools)作为"手脚"、记忆(Memory)作为"笔记本"、以及规划(Planning)能力。

## RAG 与 Agent 的关系

RAG(检索增强生成)是一种让大模型在回答问题前,先从外部知识库检索相关内容,再基于检索结果生成答案的技术。它可以有效缓解大模型的"幻觉"问题,让回答更准确、更有时效性。

Agent 常常会内置一个 RAG 检索工具,当用户的问题需要查询专业知识时,Agent 会自主决定调用这个工具去检索知识库,而不是凭空回答。

## 向量数据库

向量数据库用于存储和检索高维向量。文本经过 Embedding 模型处理后,会被转换成一组数字(向量),语义相近的文本,其向量在空间中距离也更近。

常见的向量数据库有:Chroma、Milvus、FAISS、Qdrant 等。Chroma 适合本地开发和快速原型,Milvus 更适合生产环境的大规模数据。

## 多轮记忆

为了让 Agent 在连续对话中保持一致,需要为它设计记忆机制。短期记忆保存当前对话的上下文,长期记忆则用于跨会话地记住用户偏好和重要信息。

常见的做法包括:直接保存对话历史、对历史进行摘要压缩、以及将重要信息写入向量库供后续检索。

## 工具调用(Function Calling)

工具调用是 Agent 的核心能力之一。开发者可以把某个函数(比如查询天气、计算数学题)以结构化的方式描述给大模型,模型会在需要时返回一个"调用该工具"的指令,由程序实际执行工具,再把结果返回给模型。

这个流程通常被称为 ReAct(Reasoning + Acting),即"先推理、再行动、观察结果、继续推理"的循环。
